------------------------------------------------------------
5. FIRST DEVELOPMENT MILESTONE
------------------------------------------------------------

The first major milestone is a WORKING VOICE-FIRST MVP.

A user must be able to:

1. Create an account.
2. Enter their function and role.
3. Select a communication goal.
4. Start a real AI voice conversation.
5. Hear the AI coach ask a relevant question.
6. Respond naturally by speaking.
7. Receive an appropriate spoken follow-up.
8. End the session.
9. Review evidence-backed feedback.
10. Retry the exercise independently.
11. See their learning history updated.

Build and test this core learning loop before implementing the complete achievement system, extensive scenario libraries, or advanced enterprise features.

The application must not claim that an AI conversation or communication assessment works if it is only simulated using hardcoded text.
