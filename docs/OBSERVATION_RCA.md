# Communication Coach observations and root-cause status

This note tracks the Android observations supplied on 9 October 2026. Changes described here are **local source changes**, not a new APK or Play Store release. The app has not yet been visually reviewed in Codex because the browser blocks navigation to the local preview URL.

| Observation | Root cause found | Current status in local preview | Screen to review |
| --- | --- | --- | --- |
| Spoken prompt reads the exercise title and does not sound Indian English | The speech string included the title, context, and question. The app requested `en-IN`, but did not select an installed matching device voice. | Speech now omits the title, requests an exact `en-IN` voice when available, and explains when the phone needs an Indian English TTS voice installed. Accent quality still depends on the device's installed speech engine. | Practice session → Hear prompt; Settings → Coach voice accent |
| Changing plans does not look like it worked | Selection saved to the profile, but the screen did not clearly distinguish the saved plan from store billing, and the home screen ignored plan access. | The plans screen now confirms the profile value returned by the server and labels it as the current plan. Store billing remains a preview placeholder. | Practice plans; Home → Current plan |
| Leadership appears for every package; Business Communication is unclear | Home listed all three paths unconditionally; the API recommendations did not enforce each plan's module list. | Home labels included and locked workshops from the selected plan; API recommendations and exercise creation now enforce plan modules. The professional path is named **Professional & Business Communication**. | Home → Choose a workshop; Practice plans |
| Learners should choose programmes after sign-in | The library contained five progressive skill levels but showed each level as a suffix in exercise titles rather than as an explicit choice. | The workshop now presents five named programme levels. Later levels are visibly locked until mastery unlocks them. There are **5 programmes across 3 workshops** (15 track/level combinations), with **126 library scenarios** at present: 120 generated plus 6 curated. | Home → any included workshop → Choose a programme |
| System and Dark looked identical | System mode follows the phone. The supplied screenshots show a dark phone theme, so System and Dark correctly produced the same palette. | Settings now explains this and tells the learner how to compare by choosing the opposite fixed theme. Light mode remains independently selectable. | Settings → Appearance → Theme |
| RCA requested | No single cause: the prompt composition caused the spoken title; home navigation bypassed package access; system/dark matched the phone; live AI was explicitly disabled by backend readiness/transport gates. | This RCA is recorded here; see provider and legal dependencies below. | This document |
| See My Progress needs useful stats | Progress is derived from completed conversations; an account with no completed practices naturally shows zeros. | Screen already shows streak, minutes, weekly rhythm, milestones, and a cautious text-evidence signal. It does not claim to score audio. Test with completed sessions to see non-zero values. | Progress |
| Start AI Live Coach does not work | The server returns `503` while the voice provider is unconfigured, and native WebRTC still requires verification. The control was shown even when unavailable. | The control now stays disabled and explains the exact prerequisites. **It is not yet a working AI live conversation**: provider credentials and native device QA are still required. | Practice session → AI live coach status |
| All screens should be reviewable in Codex | There was no browser-based screen-review link in this checkout. | Expo web preview was attempted, but Codex browser security rejected local-host navigation. Screens are **not visually verified** in this session; no workaround or external exposure was used. Protected screens also require sign-in. | Welcome, Onboarding, Home, Workshop, Practice, Plans, Progress, Settings, About & legal |
| Terms, privacy, and developer attribution | No legal-information screen existed. | A **draft placeholder** About & legal screen is available and credits Lucky Kiran. It is not final legal advice or store-ready policy text; verified contact details, retention/subprocessor disclosures, and reviewed terms/privacy documents must replace it before publishing. | Welcome or Settings → About, terms & privacy |
| Premium writing and formatting | Some generated exercise titles repeated their programme label, and the same generic speaking instruction was reused across scenarios. | Titles are clean and programme names are separate. All 120 generated exercises now have scenario-specific speaking tasks and transfer challenges; the app tagline and Business Communication copy are clearer. The curriculum still needs a content-owner/editorial review before it can be described as premium-final. | Home, Workshop, Practice |

## Release boundary

- These code changes are for review and regression testing only. No new EAS build has been requested or started.
- Terms/privacy remain draft placeholders, payment is not enabled, and AI Live Coach remains unavailable until its provider and native transport are configured and verified.
- The Play Console account also still needs Google identity-document approval and phone verification before store submission.
